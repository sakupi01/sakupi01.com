Renewed HTML insertion and streaming methods

Summary: One naming scheme for inserting HTML, with a safe method and an Unsafe method for each position, plus a streaming form of each. Safe methods sanitize. Unsafe methods take { sanitizer, runScripts }. Streaming uses a WritableStream from getWriter() or from Response.textStream().

Explainer: dynamic-markup-revamped-explainer.md

Docs: Declarative partial updates | Chrome for Developers

Ready for developer testing from Chrome 148 behind chrome://flags/#enable-experimental-web-platform-features. Planned for Chrome 155. Response.textStream() shipped in Chrome 151. setHTML / setHTMLUnsafe may already exist from the Sanitizer API; the positional and streaming methods are the new surface.
