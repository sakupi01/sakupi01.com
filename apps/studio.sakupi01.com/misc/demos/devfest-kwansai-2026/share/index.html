星評価

使っている API

  • <canvas content="drawable"> の子に drawable 属性を付けると、その要素は canvas の中でレイアウトされます。
  • canvas.onpaint の中で ctx.drawElementImage(element, x, y) を呼んで描きます。入力値が変わったら canvas.requestPaint() で再描画を頼みます。
  • canvas の中のフォームは絵ではなく本物の HTML なので、フォーカスもキーボード操作もスクリーンリーダーも効きます。
  • canvas.toBlob() で、見えているとおりの PNG を保存できます。
